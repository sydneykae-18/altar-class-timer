Getting Started

Set "You are" first. Tap the name field at the top and select your name. This tracks who created each class and controls who can delete it.

The app has four tabs: Build to create a class, Run Class to run it with a live timer, Classes to browse and load saved classes, and Help (you're here).

Build Tab

Class Info

Fill in the date, class type, instructor, and an optional description. The class name auto-fills from the date and class type — you can keep typing to add a theme or focus (e.g. "8.31.26 IRON 45 — Posterior Chain").

The Message / Inspo field is for your icebreaker, theme, and talking points. It shows up as a collapsible drawer when you run the class.

Blocks & Movements

  • Tap + Add Block to add a circuit block. Give it a name, set the number of rounds, then add movements inside it.
  • Each movement has Sets, Work (seconds), and Rest (seconds). Sets repeat that single movement back-to-back before moving on. Rounds repeat the whole block circuit.
  • Drag the drag handle to reorder blocks or movements.
  • The time bar at the bottom shows your estimated total vs. target length in real time.

Saving

Tap Save Class to save to the cloud — it becomes visible on any device under the Classes tab. Your draft auto-saves locally as you build.

Tap Build New to clear and start fresh. You'll be prompted to save first if you have unsaved blocks.

Run Class Tab

Before You Start

  • Choose your Sound (Classic, Bell, Beep, or Off) and Volume. Tapping either plays a preview.
  • Tap Start Class when ready. Keep your volume up — the timer beeps through your speakers.

During Class

  • Tap the WORK / REST pill to pause and resume. It shows "PAUSED" so you always know the state.
  • Tap the back/skip buttons on either side of the timer to go back or skip a step.
  • Use -10s and +15s to adjust the current countdown on the fly.
  • The volume row (Mute / Low / Med / High) is always visible — adjust mid-class without stopping anything.
  • Tap any movement in the Up Next list to jump straight to it.
  • Use Jump to block to skip ahead to any block.

Ending Class

Tap End Class at the bottom to stop and return to the setup screen.

Tip: On iPhone or iPad, tap Share → Add to Home Screen in Safari so the app opens full-screen like a native app during class.

Classes Tab

All saved classes from all instructors are listed here, newest first. Filter by class type, instructor, or keyword. Tap Load to bring a class into the Build tab. Tap Duplicate to copy it as a new class you can edit.

You can only delete classes you created. Deletions are logged and can be reviewed under Deletion history.

Tap ↻ Refresh any time to pull the latest classes from the cloud — useful if another instructor just saved something.

Class Types

  • IRON 45 — Heavy weight lifting. Time-based blocks with work/rest intervals.
  • IGNITE 45 — HIIT strength training. Time-based.
  • GROUNDWRK — Mat Pilates. Time-based.
  • ECHO — Dance cardio. Song/BPM format, no timer.
  • SYNC 45 / SYNC 60 — Cycle. Song/BPM format, no timer.
  • SYNC 30 x IRON 30 — Mixed. Each block picks its own format — SYNC (song list) or IRON (timer).
